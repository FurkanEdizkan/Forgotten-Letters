# Forgotten Letters

A self-hosted campaign companion for Trench Crusade, built first for the Carcass Front. One app container and
one PostgreSQL database, run with Docker Compose. It works with no internet connection.

An unofficial fan project, not affiliated with Factory Fortress.

- [Install](install.md): the first start and the setup wizard.
- [Port and address](port-and-address.md): which port the app listens on and the address people type.
- [HTTPS](https.md): running on the internet behind Caddy.
- [Settings](settings.md): every setting in `.env`.
- [Backups and updates](backups-and-updates.md): automatic backups, restoring, updating, getting back in.
